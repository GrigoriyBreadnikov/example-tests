🧪 Проект с автотестами API для сервиса "Vector". Проект разработан исключительно как портфолио для демонстрации навыков проектирования тестовой инфраструктуры, организации кода и работы с современным стеком инструментов автоматизации.




⚠️ Важное примечание

Данный проект является упрощенной копией реального тестового набора. Запуск тестов невозможен, так как все endpoint'ы и конфигурации были изменены или удалены для публикации. Этот репозиторий предназначен только для оценки кода и архитектуры.




🏗 Архитектура и подход

1. Проект использует комбинацию паттернов для создания чистой и поддерживаемой тестовой кодобазы:
   
2. Layered Architecture: Четкое разделение на слои: клиенты, модели, шаги, assertions и тесты.
   
3. Step Pattern: Вынесение последовательностей действий в переиспользуемые шаги (steps.py).
  
4. Allure report: Тесты подготовлены для вывода в allure-отчеты.
   
5. Custom Assertions: Централизация проверок в специализированных assertion-функциях.

6. Fixtures (Pytest): Для управления тестовыми данными, состояниями и зависимостями.

🧩 Ключевые особенности реализации

1. Модульность: Каждый сервис (vector) изолирован в собственном модуле со своей структурой.

2. Централизованная конфигурация: config.py содержит все настройки для доступа к API.

3. Специализированные assertions: assertion_main.py и assertions.py содержат кастомные проверки для удобства и читаемости тестов.

4. Фабрика данных: faker.py каждый раз генерирует новые тестовые данные, что делает выполнение тестов разнообразным.
   
5. Очистка окружения: после выполнения каждого теста данные удаляются, что гарантирует чистую базу данных

6. Step Pattern: steps.py содержит повторно используемые последовательности действий, что уменьшает дублирование кода в тестах.




🛠 Технологический стек

1. Технология	Назначение в проекте

2. Python 3.10+	Базовый язык программирования

3. Pytest	Фреймворк для написания и запуска тестов
   
4. HTTPX	Асинхронный/синхронный HTTP-клиент для взаимодействия с API
  
5. Allure-pytest	Генерация детальных и визуальных отчетов о прохождении тестов
  
6. Python-dotenv	Загрузка конфигурации из environment variables
